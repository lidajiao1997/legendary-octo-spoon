# 路线 E：事件研究型（CAR 市场反应）

适合问题：「市场如何看待某类事件」——并购公告、股票回购、高管变更、ESG 争议、ST/摘帽、定增。小而精，交易数据全自动可得。

## 1. 研究设计要素

| 要素 | 常见设定 | 说明 |
|------|---------|------|
| 事件日 t=0 | 公告日（首 个交易日对齐） | 停牌顺延到复牌日 |
| 估计窗口 | (-120, -21) | 估市场模型参数 α、β |
| 事件窗口 | (-1, +1) 到 (-10, +10) | 多窗口做敏感性 |
| 预期收益 | 市场模型：R̂ = α + β·Rm | 亦可用市场调整法（简版） |

## 2. 核心计算（Stata 实现见 assets/event_study_template.do）

```stata
* 对每个事件：估计窗口回归拿 α β
* AR_it = R_it - (α + β·Rm_it)；CAR_i(a,b) = Σ AR
* 大样本下 t 检验：CAR均值 / (CAR标准差/√N)
```

事件样本几十到几百个，从公告文件（巨潮资讯、交易所网站）手工/半自动整理事件列表：公司代码、事件日期、事件特征（金额、类型、产权）。

## 3. 检验组合

1. 全样本 CAR 是否显著异于 0（t 检验、Wilcoxon 符号秩）
2. 分组比较：国有 vs 民营、大额 vs 小额、行业——组间 CAR 差异 t 检验
3. 横截面回归：CAR(a,b) ~ 事件特征 + 公司特征（小样本用 OLS + 稳健标准误，变量数克制）
4. 稳健性：换估计窗口、换事件窗口、市场调整法 vs 市场模型法对照

## 4. 风险与清洗

- **混淆事件剔除**：窗口内有年报/分红/其他重大公告的事件要剔除并说明数量
- 剔除窗口内停牌超 N 天、上市不足一年、金融业（视研究问题）
- 小样本下非正态：用 Wilcoxon 检验佐证 t 检验

## 5. 合格线与章节映射

合格组合：≥50 个事件（50 以下说服力弱）、全样本 CAR 检验 + 至少两组比较 + 一个横截面回归 + 两项稳健性。章节映射沿用 chapter-map.md，第 4 章改为「事件定义与样本筛选 + 研究方法（含方法公式）」，第 5 章按 CAR 结果 → 分组 → 横截面的顺序展开，图（事件窗口 CAR 走势折线）是标配。
