# 路线 E 原理：事件研究——从股价里读出市场对一件事的"意外反应"

> 配套代码：assets/event_study_template.do。事件研究是半强式有效市场假说的直接应用：股价已经消化了公开信息，只有**意料之外**的部分才引起跳动。

## 1. 核心思想（一句话）

先把"没有事件时股价本该怎么走"估出来（正常收益），再用实际收益减去它——差值（异常收益 AR）就是事件带来的意外；把事件窗口内的意外加总（CAR），看市场对这件事的净评价是正还是负。

## 2. 背后的计量原理

- **市场模型**：E[ret] = α + β·rm。用事件**之前**一段"干净期"（估计窗口，如 -120 至 -21 天）回归出每只股票自己的 α、β——它刻画这家公司平日的"脾气"（随大盘涨跌的敏感度）。
- **为什么估计窗口要留 20 天缓冲**：若估计窗口太靠近事件日，市场对事件的预期会渗入 α、β 的估计，把"预期内的反应"算进正常收益，CAR 反而量不出东西。
- **AR 与 CAR**：AR_t = ret_t − (α + β·rm_t)；CAR = ΣAR。窗口选择是敏感点：短窗口（-1,+1）捕捉公告的直接冲击、噪音小；长窗口（-10,+10）混入后续信息与噪音——本技能实测中同一信号在 -1,+1 显著、-10,+10 被稀释，正说明了这一点。所以**主窗口 + 多窗口敏感性**是标配。
- **两种检验**：t 检验（假设 CAR 近似正态）与 Wilcoxon 符号秩检验（不依赖正态，小样本更稳）。两者都报告是惯例。
- **横截面回归**：CAR 作为被解释变量，解释"什么样的公司/事件市场反应更大"（金额、产权、杠杆……）。事件数通常只有几十个，变量务必克制。

## 3. 适用场景与前提

- 有明确、离散、可精确记日的事件：并购公告、回购、高管变更、ESG 争议、募资
- 样本量天然有限（几十到几百个事件）——这是该路线的定位：**小而精**
- 前提：公告日没有与财报等重大信息同日发布（信息污染）；事件日对齐到公告后首个交易日
- 注意事项：同一家公司多次事件不能视为独立样本；行业集中时推断要谨慎

## 4. 结果怎么读

- **CAR 表**："回购公告 CAR(-1,+1) 均值 0.78%，t=2.15，在 5% 水平显著为正——市场将回购解读为管理层认为股价被低估的信号"
- **t 与符号秩**：两者都显著 → 结论稳健；仅 t 显著 → 个别大值驱动，看分位数与剔除极端值后的结果
- **分组检验**：soe 组内显著、非 soe 不显著且组间差异显著 → "信号效应在民营企业中更强"之类的异质性结论
- **CAR 走势图**：事件日（rel=0）起折线应明显偏离 0——图的"视觉显著性"答辩时比数字更直观
- **经济意义**：CAR×流通市值 = 市值变动金额，"公告平均带来 X 亿元市值增长"比百分比更抓人

## 5. 常见误读（答辩高频）

1. **"窗口越长信息越全，为什么不都用长窗口？"** → 长窗口混入其他信息与噪音，识别力下降；实证上就是本技能看到的"稀释"。标准做法是短窗口为主、长窗口敏感性。
2. **"CAR 显著就是事件导致了股价变动？"** → 更准确的说法：市场对事件的**信息含量**作出了定价；前提是没有同日信息污染。答辩要主动交代"同日无其他重大公告"。
3. **"几十个样本做横截面回归可信吗？"** → 自由度极度有限；控制在 5 个以内解释变量、并报告稳健性（剔除极端 CAR 事件）。
4. **"估计窗口统一 120 天对吗？"** → 对新股、停牌重组公司要先验证估计窗口内有足够交易日，不足则缩短窗口或剔除。
