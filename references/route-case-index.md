# 路线 F：案例研究 / 综合评价型

不跑面板回归的两条支线，门槛低但对「讲道理」的要求高。

## 支线 1 · 案例研究

### 选题与设计

- **单案例**（Yin 范式）：适合「独此一家」的现象（如某标杆企业数字化转型），要论证案例的典型性/极端性（为什么值得研究它）
- **多案例**（Eisenhardt 范式）：3-6 个案例跨案例比较，复制逻辑（ literal replication / theoretical replication）做命题提炼；本科论文 2-3 个案例即可
- **理论视角先行**：动笔前必须回答「用哪个理论看这家企业」（动态能力、资源编排、双元创新、商业模式画布等）。答不上来 = 选题未成型

### 写作规范

- 资料三角验证：年报/公告 + 媒体报道 + 访谈（能拿到更好），注明资料来源编码（如「年报 2021」「访谈 A2」）
- 结构：案例背景 → 基于理论框架的过程分析（按时段或按维度）→ 跨案例比较（多案例）→ 命题/启示
- **雷区**：写成公司介绍 + 心得体会。每一段分析都要挂回理论构念；图表用「证据链表」「阶段时间轴」

### 合格线

理论视角贯穿全文、证据有来源编码、分析框架图 1 张、结论提升到理论层面（对既有理论的补充或情境化修正）。

## 支线 2 · 综合评价型（熵值法 / TOPSIS）

### 选题模式

构造某指数并评价：各省数字经济发展水平、城市营商环境、企业 ESG 表现、乡村振兴水平等。数据来自统计年鉴/政府公报（公开）。

### 熵值法流程（指标体系 → 权重 → 得分）

1. **指标体系**：3-5 个维度 × 每维度 3-5 个指标，每个指标注明出处与方向（正/负向）
2. 标准化：正向 (x-min)/(max-min)，负向 (max-x)/(max-min)
3. 熵值法客观赋权：比重 p_ij → 熵值 e_j = -k·Σ p·ln(p) → 差异系数 1-e_j → 权重
4. 加权得分，或再接 **TOPSIS**（与最优/最劣方案的距离比 C_i）排序——**直接用 `assets/entropy_topsis.py`**：`python entropy_topsis.py 数据.csv 对象列 "指标,+;负向指标,-"`，自动输出权重、贴近度得分与排名（已实测：权重合计=1，合成数据排序效度 Spearman>0.99）
5. **敏感性分析（答辩保命项）**：换等权/主成分法重算，报告排名相关性（Spearman），证明结论不依赖赋权方法

Python 或 Excel 都能算（n 个评价对象 × m 个指标），代码量小。

### 雷区与合格线

- 雷区：指标选取无文献依据；只给排名不给「为什么」（要结合维度分解解读）；权重方法单一
- 合格线：指标体系有文献支撑 + 熵值法步骤完整可复现 + 敏感性分析 + 结果按维度分解解读；进阶可把指数作为 Y/X 再跑简单回归（与路线 A 衔接）
