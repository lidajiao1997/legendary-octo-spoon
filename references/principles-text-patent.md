# 路线 B 原理：文本变量、专利度量与中介效应——把"软概念"变成数字

> 配套代码：assets/text_freq.py + pipeline_template.do。本文讲三件事的原理：词频为什么能量化"人工智能应用"、专利为什么能代表"创新水平"、中介三步法到底在检验什么。

## 1. 核心思想（一句话）

用**年报里 AI 关键词出现的频率**度量企业对人工智能的重视与应用程度（X），用**专利数量**度量创新产出（Y），再用三步法追问：X 是不是通过提升"能力 M"才促进了 Y？

## 2. 背后的计量原理

### 2.1 文本词频作为解释变量

- **思想基础**：语言是意图的载体。管理层在年报中反复谈论 AI，反映其战略注意力与资源投入——这是"管理层叙述"文献的立足点（类似文本分析已用于度量不确定性、政治风险等）。
- **构造链条**：种子词 → Word2Vec 扩充（语义相近词人工筛选）→ jieba 分词 → 只统计 MD&A 部分（管理层意图的集中表达）→ ln(词频+1)。取对数因为词频右偏严重，少数公司谈得极多。
- **口径互证**：MD&A 词频（AImda）为主、全文词频（AI_all）为辅做稳健性——两个口径结论一致，说明结果不依赖"从哪段文字数词"。
- **最大软肋**：词典主观性。答辩必问"你凭什么选这些词"。标准回应：种子词来自已发表文献 + 语义扩充 + 双口径互证。

### 2.2 专利作为被解释变量

- 专利是**创新产出的可观察代理**：申请数看投入意愿、授权数看质量门槛、被引量看影响力。本科论文常用 ln(发明专利授权数+1)，加 1 是因为大量企业当年专利为 0，ln(0) 无定义。
- 局限要写进论文：专利只覆盖"可申请"的创新，工艺改进、组织创新等不在其中；不同行业专利倾向不同（制造业 vs 服务业）——异质性检验正好回应这一点。

### 2.3 中介三步法（Baron & Kenny 传统）

设 X→Y 为总效应，三步是：

1. Y = a·X + 控制：X 对 Y 总效应显著
2. M = b·X + 控制：X 能否带动中介变量 M
3. Y = c·X + d·M + 控制：M 是否"接手"部分效应（c 较 a 变小，d 显著）

**判断**：b、d 均显著且 c 下降 → 部分中介；c 不再显著 → 完全中介。

**当代争议（答辩必备）**：逐步回归法被江艇（2022）等批评——M 的内生性会使 b、d 有偏，且"X 影响 M"与"M 影响 Y"两个环节的证据强度不等。**应答口径**：本文遵循"作用机制分析"的表述，以理论论证 X→M→Y 的逻辑链条为主，三步法提供与理论一致的实证证据；报告 Bootstrap 置信区间作为补充。

## 3. 适用场景与前提

- X 是"说不清、没有现成指标"的软概念（AI、数字化转型、ESG 表述、企业家精神）
- 有能力获取年报文本（巨潮免费）并愿意做分词处理
- 中介变量 M 要有**清晰的单向理论逻辑**（X 先于 M，M 先于 Y），否则三步法只是数字游戏

## 4. 结果怎么读

- **词频描述统计**：先报告均值、年度趋势（通常逐年上升，画趋势图加分）；ln 后标准差过大说明公司间差异悬殊，正是回归有话可说的前提
- **三步法表格**：重点读三行——第 2 步 X→M 系数（b）、第 3 步 M→Y 系数（d）与 X 系数变化（a→c）；三行全显著才能讲中介故事
- **经济意义**：系数×标准差换算成"X 提高一个标准差，Y 变化百分之几"，比裸系数更有说服力

## 5. 常见误读（答辩高频）

1. **"词频高的公司只是会写年报吧？"** → 承认叙述与行动可能背离，用双口径 + 与研发投入等硬指标的相关性佐证
2. **"中介显著就是机制被证明了吗？"** → 用上面江艇口径回答：机制是理论论证 + 一致性证据，不是"证明了"
3. **"专利多就是创新强吗？"** → 口径局限如实交代，配合异质性（高/低技术行业分组）说明
4. **"为什么用词频不用机器学习打分？"** → 本科层面词频透明可复现；打分法黑箱且词典依赖更强
