# 路线 D 原理：量表测量与结构方程——把"看不见的心理构念"变成可信的数字

> 配套代码：assets/survey_pipeline.py。问卷研究的两根支柱：**测量的信度效度**（量表量得准不准）与**假设检验**（关系是否成立）。前者不牢，后者全塌。

## 1. 核心思想（一句话）

包容型领导、心理安全感这些构念看不见摸不着，只能用一组题项间接测量；先用信效度证明"这把尺子量得准"，再谈 X 与 M、Y 之间的关系是否成立。

## 2. 背后的计量原理

### 2.1 信度：尺子稳不稳

- **Cronbach α**：所有题项之间的一致程度，直觉是"量同一构念的题应该给出相近的回答"。α≥0.7 可接受，≥0.8 良好。α 过低先查反向题是否漏翻——这是新手第一大坑。
- 注意 α 依赖题项数：题越多 α 越高，所以 α 只是底线指标，不是越高越无限好。

### 2.2 效度：尺子量的是不是那个东西

- **KMO 与 Bartlett**：做因子分析前的"体检"。KMO≥0.7 说明题项间有足够的公共方差可提取；Bartlett 显著说明相关矩阵不是单位阵。
- **EFA（探索性因子分析）**：不知道维度结构时用，看题项是否按预期归堆。
- **CFA（验证性因子分析）**：理论明确后用，检验"三因子结构"是否与数据吻合。拟合标准：CFI/TLI>0.9，RMSEA<0.08，SRMR<0.08。CFA 优于 EFA 的地方在于它是"按理论出题、按数据判卷"。
- **收敛效度**（同一构念的题项高相关：AVE>0.5）与**区分效度**（不同构念确实不同：AVE 平方根大于构念间相关）——本科论文至少报告 CFA 三因子成立，有余力再报 AVE/CR。

### 2.3 共同方法偏差

- 所有数据来自同一人同一时刻自评，会产生人为相关。**程序控制**（匿名、正反向题混排、量表分置于问卷不同位置）+ **统计检验**（Harman 单因子：第一因子解释率<40%）。两者都要写，缺一答辩就问。

### 2.4 Bootstrap 中介

- 逐步回归的间接效应抽样分布不规律，传统 Sobel 检验偏保守。Bootstrap 直接对"间接效应 = b×d"重复抽样 5000 次，用**置信区间是否含 0** 判断显著性——区间 [0.02, 0.31] 不含 0 即显著。这是当前问卷研究的标准做法。

## 3. 适用场景与前提

- 研究"人"的机制：领导力、动机、态度、行为意愿——这些构念没有二手数据
- **有效样本 ≥200**（或题项数×5）；量表必须来自成熟文献并注明出处
- 横截面设计能提供机制证据，但不能下因果结论（没有时间先后）——表述用"支持机制假设"

## 4. 结果怎么读

- **信效度表**：逐量表报 α；CFA 拟合四指标一行带过："CFI=0.988、TLI=0.981、RMSEA=0.029、SRMR=0.032，拟合良好"
- **相关矩阵**：假设涉及的两两相关应方向一致——相关都不对，回归显著性不必急着报告，先找原因
- **层级回归**：Model 1 只放控制变量 → Model 2 加 X → Model 3 加 M。看 X 的系数从 M1 到 M3 的变化讲中介故事
- **Bootstrap 表**：报告间接效应值、SE 与 95% CI，写法："间接效应 0.21，95% CI [0.09, 0.35]，不含 0，中介成立"

## 5. 常见误读（答辩高频）

1. **"400 份问卷够吗？"** → 报有效样本与题项数比例；答辩追问时说清剔除标准（答题时长、规律作答）
2. **"α=0.69 差一点点怎么办？"** → 报告"删除某题后 α=0.72"并说明该题与构念的理论关系；不可悄悄删题不提
3. **"大家都往好里说，数据可信吗？"** → 程序控制 + Harman 双保险口径
4. **"中介显著所以 X 导致 Y？"** → 横截面数据没有时间先后，只能说"结果与机制假设一致"；有条件的话用两时点数据或实验补强
5. **"量表是我自己编的行不行？"** → 本科尽量用成熟量表并注明改编之处；自编量表必须补 EFA/CFA 全套验证，工作量反而更大
