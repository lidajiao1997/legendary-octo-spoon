# 路线 A 原理：面板固定效应回归——它到底在比什么

> 配套代码：assets/pipeline_template.do。本文回答三个问题：双向固定效应凭什么能"控制"那么多东西？什么情况下结果可信？表格里每个数字怎么读？

## 1. 核心思想（一句话）

把公司与年度各自"与生俱来"的差异全部扣掉之后，看 X 变动时 Y 是否随之变动——比较的是**同一家公司自己跟自己比、同一年份公司之间比**的双重差异。

## 2. 背后的计量原理

- **为什么不能直接跑 OLS**：企业绩效同时受"这家公司是谁"（行业、品牌、治理文化）和"这一年是什么行情"（宏观周期、政策）影响。忽略它们会让 X 的系数混入这些因素，即遗漏变量偏误。
- **公司固定效应（fe）**：等价于给每家公司一个自己的截距，吸收所有不随时间变化的公司特征。直觉上：股权集中度高的公司可能本来就更赚钱（或不赚），fe 把这条"起点差异"整条抹掉，只看同一公司内部股权变动与绩效变动的共变。
- **年度固定效应（i.year）**：吸收所有公司共同经历的年度冲击（如 2020 年疫情），防止"某年大家都差"被误认为 X 的作用。
- **聚类稳健标准误（robust）**：同一公司逐年残差往往相关（今年亏明年大概也艰难），普通标准误会低估不确定性、t 值虚高；按公司聚类后诚实得多。
- **为什么要缩尾**：1%/99% 缩尾把极端值拉回分位点。一家公司营收暴增 100 倍更可能是口径变化而非真实现象，若不处理，回归会被个别点牵着走。
- **为什么要控制变量**：size、lev、age 等是理论上同时影响 X 与 Y 的"混淆因素"。控制它们是让 X 的系数更接近净效应，但**控制变量本身不是"越好越显著越好"**。

## 3. 适用场景与前提

- 适用：现成二手指标构成的「X→Y」相关性问题；样本为多家公司多年的面板。
- 两个前提要心里有数：
  1. fe 只能消除**不随时间变化**的遗漏因素——随时间变化的混淆（如某年公司恰好换了战略）它管不了；
  2. 面板固定效应估计的是**相关关系**，不是因果。要讲因果，升级到路线 C（DID）或做工具变量（pipeline.md 第 8 节）。
- 不适用：X 几乎不随时间变化（如性别）——fe 会把它一并吸收，系数估计不出来。

## 4. 结果怎么读（对着 Stata 表格逐行）

| 表格元素 | 怎么读 | 论文里怎么写 |
|---------|--------|------------|
| 系数 | X 每增加 1 单位，Y 平均变动多少 | "高管薪酬每提高 1%，ROA 提高 β 个百分点" |
| Coef. 的符号 | 与假设方向对比 | 先说方向，再谈显著性 |
| t 值 / P>\|t\| | <0.05 记 **，<0.01 记 *** | "在 1% 水平上显著" |
| R-squared（within） | 面板固定效应看 within R²，它才反映 X 与控制变量的解释力 | 一般 0.1-0.3 属正常，不必追求高 |
| 控制变量 | 只需简单交代方向是否符合常识 | 不逐个解读，防止喧宾夺主 |
| 年度/公司 FE 行 | 确认都控制了 | outreg2 的 addtext 已自动标注 |

## 5. 常见误读（答辩高频）

1. **"R² 太低是不是模型错了？"** → 面板数据个体差异被固定效应吸收后 within R² 天然不高，低不等于错；关键看 X 系数的显著性与稳健性。
2. **"显著就是因果吗？"** → 不是。显著只说明"不是巧合"；因果要靠研究设计（这是选 C 路线的理由）。
3. **"控制变量不显著要不要删？"** → 控制变量是混淆因素，留着是对的做法，删除反而引入偏误。答辩口径：控制变量的去留以理论为准，不以显著性为准。
4. **"加了年度虚拟变量为什么还要宏观控制变量？"** → 年度 FE 吸收的是全样本共同冲击；若某冲击只影响部分公司（如仅高技术行业），需要交互或分组处理。
