# 路线 B：文本词频 X + 专利 Y + 中介效应（AI→创新型论文）

适用主题：人工智能/数字化转型/ESG 表现等「文本度量型 X」对企业创新/高质量发展等「专利度量型 Y」的影响研究。范本：《人工智能对企业创新水平的影响研究——来自A股上市公司的证据》（2011–2023 A 股，双向固定效应）。

与前一路线（路线 A：薪酬→绩效）共享全部通用骨架（清洗、VIF、基准回归、出表），本文件只写路线 B 特有的三件事。

## 1. 文本词频型解释变量构造

X = ln(年报关键词词频 + 1)。完整流程（范本论文的做法）：

1. **种子词**：确定初始关键词表（如「人工智能」「机器学习」「深度学习」「神经网络」等）
2. **扩充词典**（可选加分项）：用 Word2Vec/Skip-gram 对年报语料训练，取每个种子词语义相似度前 10 的词人工筛选并入词典；无 NLP 条件时降级为人工词表（答辩口径：参考已发表文献的词典，如姚加权等）
3. **定位文本**：只统计年报 MD&A（管理层讨论与分析）部分——管理层意图的集中表达，避免全文噪声；稳健性检验换全文词频（如 AI_all）互证
4. **分词与计数**：jieba 分词（Python），把自定义词典加入分词器后按年统计每家公司词频——**直接用 `assets/text_freq.py`**：`python text_freq.py <年报txt目录> 输出.csv`，txt 按 `<代码>_<年份>.txt` 命名，自动截取 MD&A 段并输出 MD&A/全文双口径
5. **取对数**：`gen ln_ai = ln(ai_freq + 1)`，未提及即 0（脚本已输出 ln 列）

答辩必问与应答：
- 「词典怎么来的」→ 种子词 + 相似词扩充 + 参考已发表文献，报告词典词数
- 「会不会主观」→ 稳健性用全文词频替换口径，结论一致
- 数据来源：新浪财经/巨潮资讯网年报 PDF；MD&A 截取或 CSMAR「中国上市公司年报文本信息库」

## 2. 专利型被解释变量

Y = ln(发明专利授权数 + 1)（范本口径）。口径选择：

| 口径 | 特点 | 使用建议 |
|------|------|---------|
| 发明专利申请数 | 反映创新决策时点，时滞处理简单 | 常用 |
| 发明专利授权数 | 质量更高但受审查环节干扰 | 范本主口径 |
| 专利被引量 | 质量维度 | 稳健性 |
| 专利知识宽度（IPC 分类号集中度） | 创新质量替代度量 | 稳健性/异质性 |

要点：申请与授权之间存在 1–3 年时滞，正文需说明 Y 用 t 期还是 t+1 期与 X 对齐；数据来源国家知识产权局 / CNRDS / CSMAR 专利数据库；所有创新变量同样 ln(+1) 处理、1% 缩尾。

## 3. 中介效应检验（逐步回归法）

范本三中介（动态能力视角）：创新能力 IC（研发强度 + 技术人员占比，各自 min-max 标准化后加总）、吸收能力 ABC（研发支出/营业收入）、适应能力 ADA（研发、资本、广告三项支出变异系数取负）。

```stata
* 第一步：X -> Y（基准回归，已有）
xtreg eil ln_ai $controls i.year, fe robust

* 第二步：X -> M
xtreg ic ln_ai $controls i.year, fe robust
estimates store m_ic

* 第三步：X + M -> Y，看 X 系数变化与 M 显著性
xtreg eil ln_ai ic $controls i.year, fe robust
estimates store me_ic
```

逐步回归的完整判定：X→M 显著 + M 进方程后仍显著且 X 系数下降 = 部分中介。表格排布：每个中介一张三列表（X→M、X+M→Y、对照）。

**方法论风险（答辩必问）**：逐步回归法近年受质疑（江艇，2022），建议：
- 表述用「作用机制分析」而非断言「因果中介」
- M→Y 的理论逻辑要单独论证（为什么 AI 通过提升吸收能力促进创新），不能只靠系数变小说明
- 如被追问，答「本文遵循该领域通行做法，同时以理论机制论证为主要支撑，机制识别的因果性留待后续研究」

复合中介变量构造代码模式：

```stata
* min-max 标准化后加总（IC 类综合指数）
foreach v in rd_intensity tech_ratio {
    sum `v'
    gen z_`v' = (`v' - r(min)) / (r(max) - r(min))
}
gen ic = z_rd_intensity + z_tech_ratio
* 变异系数负向处理（ADA 类）
egen sd3 = rowsd(rd_exp cap_exp adv_exp)
egen mean3 = rowmean(rd_exp cap_exp adv_exp)
gen ada = - sd3 / mean3
```

## 4. 路线 B 的稳健性与内生性工具箱

| 检验 | 做法 | 备注 |
|------|------|------|
| 替换 X 口径 | MD&A 词频 → 全文词频重跑 | 与「词典主观性」质疑呼应 |
| 自变量滞后多期 | X 的 t+1/t+2/t+3 期分别回归 | 应对反向因果（创新强的企业更爱谈 AI） |
| 缩小回归样本 | 剔除特定年份/异常子样本重跑 | 范本 5.6.3 |
| 工具变量法 | 常用：同行业/同地区其他企业 AI 词频均值（leave-one-out）、历史电话机数量×年份（Nunn & Qian 交互式 IV） | 相关性 + 排他性各写一段 |
| PSM | 按是否高 AI 应用（词频高于中位数=1）1:1 或 1:4 近邻匹配，匹配后用匹配样本重跑基准 | psmatch2，平衡性检验 pstest 必须报告 |

```stata
* PSM 示例
gen high_ai = (ln_ai > r(mean)) if !missing(ln_ai)   // 或用中位数
psmatch2 high_ai $controls, outcome(eil) logit neighbor(1) common
pstest $controls, both graph
* 匹配后回归
xtreg eil ln_ai $controls i.year if _support==1, fe robust
```
