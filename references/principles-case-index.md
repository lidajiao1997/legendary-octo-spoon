# 路线 F 原理：综合评价与案例研究——没有"对照组"的研究怎么做才扎实

> 配套代码：assets/entropy_topsis.py（评价支线）。路线 F 两条支线的共同点：**不跑因果回归**，说服力来自"测量扎实"或"理论扎实"。

## 1. 核心思想（一句话）

- **评价支线**：用熵值法客观定权重、TOPSIS 算相对距离，把多个指标合成一个可比的综合得分，回答"谁强谁弱、差距多大"。
- **案例支线**：用理论当"透镜"深读一家（或几家）企业，回答"它为什么成/败"，产出的是机制命题而非统计显著性。

## 2. 背后的计量原理

### 2.1 熵值法：让数据自己说话的赋权

- 主观赋权（专家打分、AHP）的软肋是"拍脑袋"；熵值法的逻辑是**信息量定权重**：某指标在各对象间差异越大（熵越小），它区分对象的能力越强，权重越高；所有城市该指标都差不多时，它几乎不携带信息，权重趋近 0。
- 计算链：正向/负向指标统一归一化 → 比重 p_ij → 熵值 e_j = −k·Σ p·ln(p) → 差异系数 1−e_j → 归一化为权重。注意负向指标（失业率等）必须先反向化，否则"越差得分越高"。

### 2.2 TOPSIS：离理想最近、离最差最远

- 把每个对象视为多维空间中的点，找出各指标的"理想最优"与"理想最劣"，用欧氏距离算相对贴近度 C_i（0 到 1）。C_i 是**相对**排名——换一批评价对象，排名可能变，所以结论要限定在"样本内"。

### 2.3 案例研究的逻辑

- 案例不是"讲故事"：单案例靠**理论抽样**（选最典型或最反常的），用既有理论（资源基础观、动态能力、制度理论）组织证据，产出与理论对话的命题；多案例靠**复制逻辑**（literal replication 看同机制再现，theoretical replication 看对立结果验证边界条件）。
- 证据链三角化：访谈 + 档案 + 公开报道互相印证，单来源证据不足以支撑命题。

## 3. 适用场景与前提

- 评价支线：对象 ≥15-20 个（太少则权重不稳定）、指标 5-10 个且理论相关、数据来自统计年鉴等公开来源（天然免费）
- 案例支线：问题性质是"怎么发生的"（how）而非"有没有影响"（whether）；你读得进理论文献、写得了长论证
- 两者都不提供因果推断；论文不要写成"X 导致 Y"，评价支线说"综合水平排序与差距"，案例支线说"机制命题"

## 4. 结果怎么读

- **权重表**：报告各指标权重并解释"为什么数字化水平权重最高"——用差异系数讲，不是用直觉讲
- **得分与排名表**：看得分差距的结构——头部断崖式领先还是整体胶着？按区域/规模分组比较更有分析味
- **敏感性分析（保命项）**：换等权法或主成分法重算，报告与主结果的 Spearman 排名相关（>0.9 即稳健）；实测该脚本权重合计恰为 1、与构造真值的排序相关达 0.996，正是这两个检查点
- **案例论文**：命题与证据的对应表（每个命题对应哪些访谈/档案证据）是质量标志

## 5. 常见误读（答辩高频）

1. **"熵值法算出来的权重就是真实重要性吗？"** → 不是。它反映的是样本内区分度，不反映因果重要性；答辩口径：客观赋权避免了主观随意性，权重解释结合经济含义。
2. **"排名靠前的城市就是好城市？"** → TOPSIS 是相对评价，依赖指标体系与样本选择；换指标体系结论可能变——敏感性分析就是回应这个。
3. **"案例就是讲故事，怎么算学术？"** → 逐条指出：理论视角贯穿、证据三角化、命题与证据对应表。三者缺一才真的只是故事。
4. **"负向指标忘了反向化会怎样？"** → 排名系统性翻转，属于硬伤；自查方法：直觉判断排名前几名的城市是否明显反常。
