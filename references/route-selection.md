# 路线选型流程：指导学生从选题到定路线

本文件是 mgmt-thesis 技能的**入口**。学生带着模糊想法来时，按本流程四步引导，最后落到六条路线之一并转接对应 reference。

## 六路线速查表

| 路线 | 一句话模式 | 数据来源 | 核心方法 | 难度 | 因果强度 | 适合方向 |
|------|-----------|---------|---------|------|---------|---------|
| A 财务指标型 | 现成指标 X → 绩效 Y + 调节 | CSMAR 单一来源 | 双向固定效应面板 | 低 | 弱（相关性） | 公司金融、公司治理 |
| B 文本+专利型 | 年报词频 X → 专利 Y + 中介 | 年报文本 + 专利库 | 面板 + 中介 + PSM | 中 | 弱-中 | 创新、数字化转型热点 |
| C 政策评估型 | 政策试点 → 企业结果 | 试点名单 + CSMAR | DID / PSM-DID | 中 | **强** | 有政策映射的公司研究 |
| D 问卷调研型 | 心理机制 X→M→Y | 自发问卷（200+） | 信效度 + 回归/SEM | 中 | 中 | 组织行为、人力资源、营销 |
| E 事件研究型 | 事件的市场反应 | 事件列表 + 交易数据 | CAR + t 检验 | 中 | 中 | 公司金融小切口 |
| F 案例/评价型 | 深描个案或构造指数 | 案例资料 / 统计年鉴 | 案例范式 / 熵值法+TOPSIS | 低-中 | 不适用 | 战略、区域经济 |

## 学生引导四步流程

### 第 1 步：问兴趣方向（锁定路线大类）

问学生：「你对哪类问题更好奇？」
- 企业为什么赚钱/亏钱、股权薪酬治理 → 公司金融向 → 候选 A/B/C/E
- 员工为什么有干劲、消费者为什么买单 → 组织/营销向 → 候选 D
- 某家企业怎么成功的 → 战略案例向 → 候选 F
- 政策到底有没有用 → 政策评估向 → 候选 C

### 第 2 步：数据可行性检查（一票否决项）

按顺序确认三件事，任何一件答不上来就该换路线（**数据库权限的完整判定看 env-and-data.md 第二节权限矩阵**——哪些数据源免费、哪些付费、没权限时的降级替代都在那里）：
1. **学校有什么数据库权限？** 有 CSMAR/Wind → A/B/C/E 全开；都没有 → D（自己发问卷）或 F（公开统计年鉴），E 可用免费交易数据但清洗工作量大
2. **能不能坚持收 200+ 份有效问卷？** 不能就别选 D
3. **会不会（或愿不愿学）Python 分词？** 不会且不想学 → B 降级为 A 或直接换 C

### 第 3 步：工具箱自评（定方法上限，软硬件门槛对照 env-and-data.md 第一节）

- 只会 Stata 点菜单 → 锁定 A 或 F 的综合评价
- Stata 会写 do 文件 → A/C/E 任选
- 会一点 Python → B 可行
- 会 SPSS → D 可行

### 第 4 步：出「最小可行选题」并定路线

用句式帮学生把想法收窄成一句话：「___（X）对___（Y）的影响研究——基于___（样本/政策/机制）的证据」。产出选题后：

- 选定路线 → 立即转接对应 reference：A/B 见 pipeline.md 与 route-text-patent.md，C 见 route-did.md，D 见 route-survey.md，E 见 route-event-study.md，F 见 route-case-index.md
- 按该路线 reference 里的「合格线」清单反查选题是否撑得起论文（检验不够就加机制或换 Y）

## 选型决策树（文字版）

```
有上市公司数据权限？
├─ 否 ── 能收 200+ 问卷？── 是 → D（问卷 SEM）
│        └─ 否 → F（案例 / 公开统计年鉴综合评价）
└─ 是 ── 研究对象是一项政策/试点？
         ├─ 是 → C（DID）
         └─ 否 ── X 是「说不清的软变量」（AI、数字化、ESG）？
                  ├─ 是 → B（文本词频 + 专利）
                  └─ 否 ── 关心的是某类事件的股价反应？
                           ├─ 是 → E（事件研究）
                           └─ 否 → A（财务指标回归 + 调节）
```

## 常见错误选型（引导时要拦住）

1. **想讲因果却选了 A**：「政策/事件对企业的影响」类问题用路线 A 只能说相关；有政策时点就改 C
2. **不会 Python 却选 B**：文本构造是 B 的大头工作，工具不匹配要么降级要么换线
3. **只有 60 份问卷就选 D**：样本不足做 CFA 都困难，先想清楚发放渠道再定
4. **题材饱和还在选 A**：股权集中度→绩效这类组合已被写烂，引导换 Y（如 ESG 表现、全要素生产率）或换机制
5. **F 类案例没有理论视角**：先问「用哪个理论看这家企业」，答不上来就先读文献再定题
