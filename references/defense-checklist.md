# 盲审与答辩自查清单

交稿前逐项过一遍。任何一项答不上来都先补课或补检验。通用部分适用于所有路线；问卷类论文（路线 D）另过末尾的「路线 D 专查」段。

## 数据与样本

- [ ] 数据来源写明（CSMAR/Wind），样本区间、行业筛选标准交代清楚
- [ ] 报告最终样本量：多少家公司 × 多少年，与删除标准一致
- [ ] 缩尾处理说明（上下 1%）出现在研究设计章节
- [ ] 剔除金融业（如适用）、ST 公司的处理是否说明（本科论文可不做但被问到要能答）
- [ ] 面板设置正确：`xtset id year`，无重复 code-year

## 变量

- [ ] 变量定义表完整：符号、名称、度量方式、来源
- [ ] 解释变量取对数的理由（量纲、偏态）
- [ ] 控制变量选了哪些、为什么（每个控制变量对应一句文献或理论理由）
- [ ] VIF 已报告且 < 10（交互项回归前尤其要报）

## 模型与检验

- [ ] 固定效应 vs 随机效应的选择有交代（Hausman 检验或理论说明）
- [ ] 标准误处理说明：聚类到公司层面
- [ ] 稳健性检验 ≥ 2 项，方法互不相同
- [ ] 内生性检验 ≥ 1 项；若用工具变量，能口头讲清相关性与排他性
- [ ] 调节效应：交互项 + 分组回归双保险，简单斜率图已画
- [ ] 每个回归表注明固定效应与标准误形式

## 写作规范

- [ ] 所有表格三线表，编号连续且正文有引用
- [ ] 显著性标注统一（*/**/*** 阈值在表注说明）
- [ ] 结果分析段落有具体系数与显著性水平，不是「结果见下表」
- [ ] 结论逐条回应假设；对策建议与实证发现对应
- [ ] 参考文献 GB/T 7714 格式，近 5 年文献占比合理
- [ ] 摘要含方法、数据、核心发现、建议四要素

## 答辩高频问题（提前备好口头答案）

1. 你的创新点是什么？（答题模板：相对现有文献，在样本/视角/调节机制上的边际贡献，一句话说清）
2. 为什么用固定效应而不是随机效应？
3. 薪酬和绩效谁决定谁？怎么处理反向因果？（答滞后 + 工具变量）
4. 工具变量「同行业其他公司平均薪酬」凭什么外生？
5. 调节效应显著/不显著分别怎么解释？
6. 你的结果对政策有什么含义？不要夸大，本科论文说「提供经验证据」即可
7. 如果换一个被解释变量（如 ROE 换 TobinQ），结论还成立吗？（答：已做，见基础回归表三列一致）

## 常见雷区

- 用「拟人化因果」表述：相关不等于因果，正文表述用「正向影响/显著相关」，在交代内生性处理后才可以谨慎使用「因果」
- 表格从 outreg2 直接截图贴 Word（要整理成三线表）
- 描述性统计与回归样本量对不上（缩尾/删除顺序不一致导致）
- 结论建议与实证结果脱节

## 路线 D 专查（问卷调研型；通用段中不适用于问卷的项目跳过）

### 样本与问卷

- [ ] 报告发放量、回收量、有效量及剔除标准（答题时长、规律作答、反向题矛盾）
- [ ] 每个量表注明来源文献与题项数、计分方式（Likert 几点）
- [ ] 有效样本 ≥ 200（或 ≥ 题项数×5）
- [ ] 样本人口学分布表（性别、年龄、学历、司龄）已呈现

### 测量质量

- [ ] 各量表 Cronbach α ≥ 0.7；若某量表 α 偏低，「删题后达标」要写明删了哪题及理由
- [ ] KMO ≥ 0.7、Bartlett 显著；CFA 拟合 CFI/TLI > 0.9、RMSEA < 0.08、SRMR < 0.08
- [ ] 收敛效度（AVE > 0.5, CR > 0.7）与区分效度（AVE 平方根 > 相关系数）已报告或至少 CFA 三因子结构成立
- [ ] Harman 单因子（第一因子 < 40%）已报告；程序性控制（匿名、反向题）有交代

### 假设检验

- [ ] 反向题已反向计分（描述统计均值合理，无异常低 α）
- [ ] 相关矩阵与假设方向一致；不一致时正文有解释
- [ ] 层级回归逐步报告（仅控制 → +X → +M）；中介用 Bootstrap（5000 次，95% CI 不含 0）
- [ ] 调节假设：交互项前变量已中心化；简单斜率图（可选加分）
- [ ] 部分假设不显著时如实报告并给理论解释，不删结果

### 答辩高频（路线 D 版）

1. 「你的问卷是随便发的吗？」→ 渠道 + 回收率 + 剔除标准三件套作答
2. 「大家都自己填自己，会不会都往好里说？」→ 共同方法偏差的程序控制 + Harman 检验
3. 「量表是哪来的？」→ 逐量表报出处文献，说明改编（如情境从「员工」改到「新生代员工」）
4. 「中介是因果吗？」→ 横截面数据提供机制证据而非严格因果；「支持机制假设」的表述口径
