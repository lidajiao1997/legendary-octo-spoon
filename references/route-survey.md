# 路线 D：问卷调研型（SEM / 回归）

适合问题：个体微观心理机制（领导风格→员工行为、CSR→购买意愿、创业环境→创业意向）。不碰上市公司数据，成本在收问卷。

## 1. 选题模式

X（组织情境/领导/氛围）→ M（心理感知：信任、认同、动机）→ Y（行为/意愿/绩效）。理论库：社会交换理论、自我决定理论、计划行为理论、社会认知理论、资源保存理论。

**量表必须用成熟量表改编**（注明来源文献），Likert 5 点或 7 点。全新自编量表是硕士以上工作量，本科不要碰。

## 2. 问卷与样本

- 变量数控制在 5-8 个潜变量，问卷 2 页内，5-8 分钟填完
- 有效样本 ≥ 200（经验法则：样本量 ≥ 潜变量题项数 × 5，最好 ×10）
- 发放渠道：问卷星 + 企业/班级定向；记录回收率与无效卷剔除标准（答题时间过短、反向题矛盾、规律作答）

## 3. 分析管线（顺序固定）

1. 反向题反向计分；剔除无效样本
2. **信度**：各量表 Cronbach α ≥ 0.7
3. **效度**：KMO ≥ 0.7 与 Bartlett 显著 → EFA（探索）或直接 CFA（验证）；CFA 拟合标准 CFI/TLI > 0.9、RMSEA < 0.08、SRMR < 0.08；收敛效度 AVE > 0.5、CR > 0.7；区分效度 AVE 平方根 > 相关系数
4. **共同方法偏差**：Harman 单因子检验（第一因子方差解释 < 40%）
5. 描述统计 + 相关矩阵
6. **假设检验**：层级回归（逐步加入控制变量）或 SEM；中介用 Bootstrap（5000 次，95% 偏差校正置信区间不含 0 即显著）；调节用交互项（变量先中心化）
7. 差异分析（可选）：t 检验/方差分析看人口学变量组间差异

## 4. 工具选择

- **SPSS + AMOS**：本科最常见组合，答辩老师最熟悉
- **Python 管线**（本技能默认）：`assets/survey_pipeline.py`，一条命令跑完 清洗→α→KMO/Bartlett→CFA（含 CFI/TLI/RMSEA）→Harman→相关→层级回归→Bootstrap 中介，输出汇总 markdown。用法：`python survey_pipeline.py 数据.csv 输出.md`；量表编码在脚本头部 X_ITEMS/M_ITEMS/Y_ITEMS 处改。已用 400 人合成数据实测通过（α≈0.79、CFI≈0.99）
- **注意**：反向题列表 REVERSE 必须与真实反向题一致，配错会表现为某量表 α 异常低（<0.3）——遇到先查反向题
- R (lavaan) / SmartPLS（偏最小二乘，样本小时更稳）亦可

## 5. 答辩高频问题与应答

1. 「样本代表性？」→ 报告发放/回收/有效数量与渠道，承认便利样本局限，落在局限部分
2. 「共同方法偏差怎么办？」→ 程序控制（匿名、反向题）+ 统计检验（Harman）；进阶可提单因子 CFA 对照
3. 「为什么用回归不用 SEM / 反之？」→ 回归看路径逐条检验更直观；SEM 同时估计测量与结构，样本够、模型简单时两者结论应一致
4. 「中介是因果吗？」→ 横截面问卷只能提供机制证据，非严格因果，结论用「支持……的作用机制假设」

## 6. 合格线

信效度全达标 + 共同方法偏差检验 + 全部假设有检验结果（部分不显著可如实报告并给解释）+ 中介/调节至少各一组。章节映射沿用 chapter-map.md，第 4 章改为「问卷设计与样本说明」，第 5 章按上面管线顺序组织。
