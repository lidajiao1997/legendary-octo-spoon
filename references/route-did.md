# 路线 C：政策评估型（DID / PSM-DID）

适合问题：「某项政策/试点对企业 X 的影响」。因果识别最规范的一条路线，答辩优势最大。

## 1. 题材库（试点政策，名单公开可查）

低碳城市试点、智慧城市试点、「宽带中国」试点、排污权交易试点、沪深港通标的调整、注册制改革、碳排放权交易、国家级大数据综合试验区、科创政策试点等。处理组 = 入选试点的城市/企业名单（政府文件逐批整理），对照组 = 其余样本。

## 2. 数据结构

公司 × 年度面板，需要三个关键变量：

```stata
gen treat = 0
replace treat = 1 if <公司/城市在试点名单>        // 处理组
gen post = (year >= <该试点批次年份>)              // 多期试点按公司/城市各自时点
gen did = treat * post
```

## 3. 基准回归（Stata 16 基线）

```stata
* 双向固定效应 DID（多期）
reghdfe y did $controls, absorb(id year) vce(cluster id)
* 或 xtreg 等价写法
xtreg y did $controls i.year, fe robust
```

## 4. 平行趋势检验（必做，答辩必问）

事件研究式：以政策前一期为基准，放相对时间虚拟变量，画系数图。

```stata
gen rel = year - <政策年份>
* 手动生成 rel = -5..+5 的虚拟变量（去掉 -1 为基准），事件研究图用 coefplot
```

标准：政策前各期系数不显著且围绕 0，政策后显著偏离。前趋势不平行时：PSM 匹配后再 DID，或换对照组。

## 5. 稳健性工具箱

| 检验 | 做法 |
|------|------|
| PSM-DID | 按 $controls 逐年 1:1 近邻匹配（psmatch2），用匹配样本重跑 |
| 安慰剂检验 | 随机打乱处理组/政策时点，重复 500 次看 did 系数分布（permutation） |
| 排除同期政策 | 控制同期其他试点的虚拟变量 |
| 替换 Y / 剔除特殊样本 | 更换被解释变量度量；剔除直辖市、疫情年份等 |
| 预期效应 | 政策宣布年早于实施年时，用宣布年做 post |

## 6. 进阶提醒（写进局限或加分）

多期 DID 下双向固定效应估计可能有「异质性处理效应偏误」（坏对照组问题），本科论文用双向固定效应即可，但可在局限一节点名，并在附录用 csdid / did_imputation 稳健性对照（本机 Stata 已装；调用前 `capture which` 确认）。

## 7. 合格线与论文章节映射

合格组合：基准 DID + 平行趋势图 + ≥3 项稳健性（含安慰剂）+ 机制（中介或调节均可，复用 A/B 路线方法）+ 异质性（区域/产权/规模）。章节顺序与 chapter-map.md 通用，第 5 章在基准回归前多一节「政策背景与识别策略」（讲清楚为什么 DID、处理组怎么定义）。
