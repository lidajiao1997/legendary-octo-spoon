# 路线 C 原理：双重差分（DID）——用"没被选中的对照组"还原因果

> 配套代码：assets/did_template.do。DID 是本科阶段能拿到的最强因果证据，但前提纪律也最严。本文讲清它的因果逻辑从哪来、平行趋势为什么是生命线、安慰剂在防什么。

## 1. 核心思想（一句话）

政策打在一部分个体（处理组）身上、没打在另一部分（对照组）身上；用**对照组同期变化**扣除掉"就算没政策也会发生的变化"，剩下的差就是政策的净效应——这就是"双重差分"名字的由来。

## 2. 背后的计量原理

- **反事实思维**：我们真正想知道的是"受政策企业**如果没受政策**会怎样"——这永远观察不到（反事实）。DID 的思路是用对照组当替身：假设没有政策时，处理组会沿着与对照组相似的趋势变化。
- **这个假设就是平行趋势**：政策前处理组与对照组走势一致（系数围绕 0），政策后分道扬镳。它是 DID 全部因果说服力的来源，所以叫生命线。
- **双向固定效应**：`reghdfe Y did, absorb(id year)` 中 did=treat×post。公司 FE 吸收两组的"起点差异"，年度 FE 吸收共同冲击，did 系数捕捉"处理组在政策后多出来的那截变化"。
- **多期 DID**：政策分批推开时（如低碳城市两批试点），不同个体在不同年份"开关"。用相对时间（rel = year − 政策年份）统一对齐，基准期取政策前一期。
- **为什么标准误按公司聚类**：同一个公司被政策影响的效应逐年相关；且处理组往往在地理/行业上聚集，截面相关也会低估标准误。
- **PSM-DID 的角色**：匹配是给"平行趋势受质疑"上一道保险——先用可观测特征配平两组，再跑 DID。它解决不了不可观测差异，这一点论文里要如实说。

## 3. 适用场景与前提

- 有明确政策/试点，且**处理组名单可查**（政府文件、部委公告）
- 对照组充足且政策未"外溢"到对照组（如试点城市的邻市受波及，要剔除或讨论）
- 政策时点不能恰好撞上其他大事件（同期政策混淆）
- 处理组不是按结果变量筛选的（"谁表现差谁进试点"会彻底毁掉识别）

## 4. 结果怎么读

- **基准表**：did 系数即平均处理效应。"did 系数 0.388，在 1% 水平显著——试点使企业创新产出平均提高约 0.39 个单位"。
- **平行趋势图**：横轴相对政策时点。**政策前（pre）各点置信区间应跨 0**——这是"走势本来一致"的证据；current 起系数转正、逐年走强则说明效应随时间显现。政策前若有一个显著的非零点，全文结论降级，需换基准期/剔除该期/换对照组重试。
- **安慰剂图**：500 次随机指派伪处理组的系数分布应集中在 0 附近，真实系数落在分布右尾——"我们的结果不是随便挑一组人也能跑出来的"。
- **PSM-DID 表**：与基准系数方向一致、量级相近 → 结果不依赖样本选择。

## 5. 常见误读（答辩高频）

1. **"平行趋势不平行但很接近，能不能糊弄？"** → 不能。答辩老师第一个就看这张图。补救：更换基准期、缩窗口、剔除率先实施者、换对照组。
2. **"交互项显著就等于政策有效？"** → 还需排除同期混淆、安慰剂检验、预期效应（政策公布前就反应）。
3. **"对照组越大越好吗？"** → 对照组要"像"处理组，不是"多"。用从未试点 + 可比特征筛选，比全样本塞进去更可信。
4. **"为什么 2020 年要剔除？"** → 疫情对处理组与对照组冲击不同步时，会污染 DID 差分；常规做法是剔除或加交互控制。
